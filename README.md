# SAP ABAP Inventory Management System

## Project Overview

The SAP ABAP Inventory Management System is a custom SAP ABAP application developed to manage material stock and stock transactions efficiently.

The system manages stock inward and outward transactions and provides current stock information through ALV reporting.

## Key Features

- Material master management
- Stock inward and outward transactions
- Current stock calculation
- Create, Read, Update, and Delete (CRUD) operations
- Selection screen for user input
- ALV report for stock information
- Identification of low-stock and out-of-stock materials
- Custom SAP database tables

## SAP ABAP Concepts Used

- ABAP Reports
- Data Dictionary (DDIC)
- Custom Tables
- Internal Tables
- Open SQL
- Selection Screens
- Modular Programming
- ALV Reports
- Debugging
- Function Modules

## Technologies

- SAP ABAP
- SAP GUI
- SE38
- SE11
- SM30
- ABAP Debugger

## Project Workflow

1. Maintain material information.
2. Record stock inward and outward transactions.
3. Calculate current stock.
4. Display stock information using ALV reports.
5. Identify low-stock and out-of-stock materials.

## Project Outcome

The project provided practical experience in SAP ABAP development, database operations, internal table processing, ALV reporting, and debugging.
